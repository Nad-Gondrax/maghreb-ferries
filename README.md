# Maghreb Ferries

MVP Next.js pour comparer les ferries vers le Maroc, l'Algerie et la Tunisie avec un focus diaspora, famille, voiture, bagages et trajets d'ete.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Supabase pour les leads et clics affilies

## Local

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.
